## Overview

Arturia SQ80 V recreates the cult Ensoniq SQ-80 hybrid wavetable synthesizer, known for its gritty wavetable oscillators, digital-analog hybrid architecture, and distinctive digital character.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Arturia SQ80 V** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Wavetable OSCs** | Ensoniq wavetable oscillators with the original waveform library |
| **Curtis Filters** | CEM3396 analog filter chip emulation for warm analog character |
| **Arpeggiator** | Original SQ-80 arpeggiator and step sequencer recreated |
| **Expanded Library** | Additional wavetables and presets beyond the original hardware |
